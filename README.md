
# Análise de Dados de Conversas do WhatsApp

## Descrição
Aplicação desenvolvida em Python para analisar conversas exportadas do WhatsApp em formato TXT.

## Funcionalidades
- Importação de arquivos TXT.
- Exibição das mensagens em DataFrame com Pandas.
- Resumo da quantidade de mensagens por remetente.
- Consulta do histórico por remetente.
- Gráfico de barras com mensagens por dia.
- Gráfico de pizza com o percentual de mensagens por remetente.
- Gráfico de linhas com a evolução diária das mensagens.

## Tecnologias utilizadas
- Python
- Pandas
- Matplotlib
- Streamlit

## Como executar
1. Instale as dependências com `python -m pip install -r requirements.txt`.
2. Execute `python -m streamlit run app.py`.
3. Abra o endereço local apresentado no terminal.
4. Importe um arquivo TXT exportado do WhatsApp.
